# SW KAILASH RESTAURANT CUM HALL Website

Official responsive web application for **Kailash Restaurant Cum Hall**.

## 🌟 Features
- 🍽️ Interactive Food Menu & Pricing (`menu.html`)
- 📱 Fully Responsive Mobile-First Design (`index.html`, `styles.css`)
- 📸 Dynamic Assets & High-Quality Compressed WebP Images (`/assets`)
- 💬 WhatsApp Direct Ordering & Table Booking Integration
- ⚡ Optimized Performance & Fast Loading

## 🚀 How to Run Locally
Open `index.html` in any modern web browser or use Live Server in VS Code.

## 🔄 Updating to GitHub
You can update this repository easily anytime by double-clicking `git-update.bat`.
